GitHub Mermaid JSDoc Viewer

Previews Mermaid diagrams found in JSDoc comments (and Markdown fences) on GitHub — in files, pull requests, commits and compare views.
Quick start
  1. Open a .js/.ts or Markdown file, a PR, a commit or a compare view
  2. Click the 📊 badge next to a ```mermaid fence to preview it (🔀 = the diagram changed — shows before/after)
  3. Scroll to zoom, drag to pan, double-click to reset — or Open in Mermaid Live ↗
Privacy
Nothing is collected. The diagram text is sent to mermaid.ink / mermaid.live only when you click.
