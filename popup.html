GitHub Mermaid JSDoc Viewer

Finds Mermaid diagrams inside JSDoc comments while you browse source files on GitHub, and lets you preview or open them in the Mermaid Live editor.
Quick start
  1. Open any .js/.ts file on GitHub ("blob" view)
  2. Look for the action bar under a ```mermaid fence in a JSDoc comment
  3. Click Display diagram to preview it inline
  4. Click Open in Mermaid Live to edit it in the full editor
Preview controls
Scroll to zoom, drag to pan, double-click to reset.
